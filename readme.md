# 📱 每日语录 (Daily Quotes MD3)
一款基于 **Material Design 3 (莫奈风格)** 的单文件沉浸式随身语录网页应用。无第三方框架依赖，纯原生 HTML5/CSS3/JavaScript 编写，支持离线使用、自定义时区、手势交互与深度词库管理。
## ✨ 核心特性
### 🎨 1. MD3 莫奈动态色彩美学
 * **优雅界面**：延续 Material 3 核心规范（大圆角、色调映射、悬浮卡片、自然动效）。
 * **多色调切换**：支持在设置页一键切换四种精心调配的莫奈浅色系主题（**浅天蓝**、**浅草绿**、**浅樱粉**、**浅水灰**）。
 * **沉浸式体验**：首页背景、文字与卡片色彩随选定主题动态计算，呈现高可读性、无割裂感的视觉延伸。
### 🔄 2. 动感交互与全屏沉浸
 * **隐藏式常驻底栏**：打破传统底栏对视野的遮挡，改为“全屏铺满底部”设计。
 * **空白触控调度**：首页默认全屏隐藏导航栏。**点击任意空白处**呼出底栏，**再次点击**即可恢复极致全屏。
 * **自然滑动手势**：首页支持全屏触摸层级捕获：
   * 向左滑动 → 切换至**上一条**语录
   * 向右滑动 → 切换至**下一条**语录
### ⏰ 3. 精准时区感知
 * **无感时钟**：首页显眼位置渲染动态时间和日期（含星期）。
 * **多时区支持**：默认跟随系统时间，亦可在设置中自由切换“北京时间、纽约时间、伦敦时间”等。日期与星期会自动根据所选时区完成跨日逻辑转换。
### 🗃️ 4. 深度语录库管理 (词库 Mode)
 * **双模式弹窗**：全新重构的底部分离式抽屉弹窗：
   * **查看模式**：以细腻的 Material 列表平铺浏览当前所有本地词库。
   * **编辑模式**：点击一键切换，即可直接在文本域内直接通过换行进行文本级批量修改、删除或贴入新语录。
 * **多格式兼容导入**：
   * 支持选择本地 .txt 或 .json 文件导入。
   * 智能解析规范的 "语录内容","语录内容" 的 CSV 风格文本及纯换行文本。
### 🛡️ 5. 数据安全与网页功能屏蔽
 * **防误触防外挂**：全面屏蔽长按选择、鼠标右键菜单、高亮复制等原生网页行为，打造宛如原生 App 的沙盒级纯粹阅读感。
 * **独立备份/恢复**：支持一键导出包含完整语录库+时区+主题设置在内的标准化 .json 备份文件，换设备亦能秒级复原。
## 🛠️ 技术架构
项目坚持**轻量、无感、单文件**的设计初衷：
| 模块 | 技术选型 | 作用说明 |
|---|---|---|
| **核心骨架** | HTML5 Semantic Tags | 纯原生单文件，零外部资源拉取（除 Google Fonts 矢量图标库外） |
| **视觉样式** | CSS3 Flexbox / CSS Variables | 基于原生变量实现动态 MD3 色彩系统，拒绝卡顿的重排动效 |
| **动态逻辑** | Vanilla JavaScript (ES6+) | 纯原生 JS 状态驱动，高效处理手势捕获与时区时间偏移算力 |
| **持久化** | LocalStorage API | 状态、主题及语录词库均在用户浏览器本地强绑定存储，保护隐私 |
## 📐 系统动态色板 (Palette Matrix)

## 🚀 快速开始
### 安装与运行
由于该项目为**单文件 HTML 架构**，您无需安装任何运行环境：
 1. 下载或复制代码，将内容保存为 index.html。
 2. 在任意移动端或桌面端浏览器（Chrome, Safari, Edge, 夸克等）中**直接双击打开**即可。
### 语录导入标准格式样例
如果您需要批量导入语录，请确保文件满足以下任一格式：
#### 格式 A: .txt (标准 CSV 逗号分隔)
```text
"生活不是等待风暴过去，而是学会在雨中翩翩起舞。","星光不问赶路人，时光不负有心人。","保持热爱，奔赴山海。"

```
#### 格式 B: .json (标准一维数组)
```json
[
  "生活不是等待风暴过去，而是学会在雨中翩翩起舞。",
  "星光不问赶路人，时光不负有心人。",
  "保持热爱，奔赴山海。"
]

```
## 📝 使用须知
> **关于数据丢失说明**：本应用的数据存储在浏览器的 LocalStorage 中。如果您手动清理了浏览器的“缓存与网站数据”，本地语录库可能会被一并清空。建议定期在设置中点击 **“备份数据”** 导出 .json 文件进行本地妥善保存。
